# Setting up Secrets

Set up secrets in PhantomX and share them across teams or keep them private.

## Overview

Upload or set key values in the Secrets section. Set permission access across the organization. Secrets are stored in a secured encrypted vault.

## Usage in Workspaces

Secrets selected during workspace creation are automatically set in the .env file in respective repositories.

If you select multiple secret files while creating a workspace, all selected secrets are appended to the .env file in respective repositories.
