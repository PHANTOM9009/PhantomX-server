# Phantom: AI Coding Agent

Phantom is an autonomous AI coding agent that completes development tasks with minimal human intervention on the PhantomX platform.

## Core Capabilities

### Autonomous Task Completion
- Analyzes task requirements and specifications
- Plans and implements solutions
- Tests and debugs implementations
- Verifies changes meet requirements
- Delivers only working features

### Full-Stack Debugging

**Backend:**
- Execute and analyze server-side code
- Monitor API responses and database queries
- Identify and fix runtime errors
- Review server logs and error traces

**Frontend:**
- Interact with browser-based applications
- Inspect DOM elements and CSS
- Monitor network requests
- Analyze JavaScript errors

### Browser Automation
- Automated browser manipulation via sandbox environment
- Element inspection and interaction
- Screenshot capture
- Network traffic monitoring
- Console log analysis
- No manual screenshot sharing required

### Code Search with RAG
- Semantic code search across entire codebase
- Fast search through complex projects
- Context-aware code retrieval
- Function and variable usage tracking

### Web Search
- Technical documentation lookup
- Error message research
- Library and framework documentation
- Filtered for development-related content

## Working with Phantom

**Task Assignment:**
- Provide clear task description
- Define acceptance criteria
- Include relevant context
- Specify constraints

**Monitoring Progress:**
- Real-time status updates
- Step-by-step action logs
- Code change previews
- Test results

**Effective Task Descriptions:**
- Specify exact requirements
- Include examples when helpful
- Define success criteria
- Reference related issues

## Getting Started

1. Set up a workspace with your repository
2. Configure necessary secrets and system prompts
3. Create a task with clear requirements
4. Let Phantom work autonomously
5. Review and approve results
